# UAE CRM Final Supabase Secure

Statická GitHub Pages verze napojená na Supabase.

## Nasazení
1. ZIP rozbalte.
2. Nahrajte `index.html`, `.nojekyll`, `README.md` do GitHub repository.
3. Commit changes.
4. GitHub Pages nastavte na Deploy from branch → main → /root.
5. Nepoužívejte GitHub Actions/Jekyll build.

## Poznámky
- Přihlášení a registrace běží přes Supabase.
- Role a oprávnění hlídá Supabase RLS.
- CSV export používá středník.
